# archivos

Documentos del Proyecto Cultural Barranco que circulan fuera y necesitan una dirección fija.

Cada documento vive en su propia [release](https://github.com/barranco-life/archivos/releases). El archivo con nombre fijo es siempre la versión más reciente; al lado quedan las versiones anteriores, numeradas. Este repositorio no guarda archivos pesados en su historial.
